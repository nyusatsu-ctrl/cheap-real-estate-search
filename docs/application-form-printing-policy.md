# 信販会社申込書の機械印字運用方針

## 株式会社アスト

- 株式会社アストから、申込書への機械印字・顧客情報の自動転記による作成について事前に運用許可を得ている。
- 「アスト申込書作成」の編集、プレビュー、B5 PDF作成機能は正式運用対象として維持する。
- 自動転記と機械印字は、原本の「申込者氏名」欄以降の申込者、住居・家族、緊急連絡先、勤務先情報だけを対象とする。
- 車両、販売店、申込日、申込条件、借入金額、現在借入など氏名欄より上の項目は、編集画面とPDFのどちらにも値を渡さず原本のまま空欄とする。
- 顧客管理から自動転記した値を含め、対象範囲の全項目をPDF作成前に人間が修正できる状態を維持する。
- この機能からアストへの正式申込、FAX送信、メール送信は行わない。作成後の提出は別の承認済み手順で行う。

## プレミア

- プレミアから、申込書の機械印字・自動印刷は不可との回答を受けている。
- プレミア申込書は手書き運用とし、申込書の自動転記、PDF自動生成、自動印刷を利用しない。
- 書面による再許可と社内の変更承認が確認できるまで、プレミア申込書の機械印字機能を再有効化しない。
- 誤操作や画面改変で実行されないよう、管理画面、GASサーバー、VercelのPDF APIのすべてで停止する。
- Vercelのプレミア申込書画面は手書き運用の案内だけを表示し、印字位置調整画面は公開しない。

## 影響しない既存機能

この方針は申込書の機械印字だけを対象とする。プレミアの審査依頼、審査結果管理、否決メール、顧客管理、契約管理など、申込書印字以外の既存業務機能は変更しない。
